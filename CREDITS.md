# Map data credits

The landscape (terrain shape, land cover, vegetation placement) of generated routes is derived from open data:

- **Land cover:** ESA WorldCover 10 m 2021 v200, © ESA WorldCover project / Contains modified Copernicus Sentinel data (2021)
  processed by ESA WorldCover consortium, CC BY 4.0 (<https://esa-worldcover.org>). Downloaded once per route by
  `Story Cycling > WorldGen > Fetch Land Cover for Selected Route` and stored resampled in `Assets/StoryCycling/WorldGenData/*.landcover.bytes`.
- **Roads, buildings, land use:** © OpenStreetMap contributors, ODbL (<https://www.openstreetmap.org/copyright>).
- **Terrain heights:** AWS Open Data "Terrain Tiles" (Terrarium), see <https://github.com/tilezen/joerd/blob/master/docs/attribution.md>.
